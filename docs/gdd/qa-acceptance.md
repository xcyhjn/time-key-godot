# 《时之钥》Godot 原作 QA 验收规范

## 使用边界

本规范把当前实现验收和未来补全验收分开。只通过源码、直接场景或调试按钮得到的结果必须标记 TARGETED_ONLY，不能替代自然玩家流程。

## 门禁

| 门 | 通过条件 |
| --- | --- |
| G0 启动 | Godot 4.6.2 启动；主菜单六命令可见；无存档 Continue 不误启动。 |
| G1 局外 | 新游戏、seed、角色确认、相邻/非法移动、普通节点切入可重复。 |
| G2 战斗 | 牌堆/手牌、敌意、3×12 时间轴、目标、结束回合、空格转币可重复。 |
| G3 结算 | 普通胜利、奖励、返回局外、存档和重复领取无错误。 |
| G4 内容 | 精英、事件、商店、Boss、教程、胜利、失败均有自然证据。 |
| G5 发布 | 存档迁移、窗口/焦点、音频、全屏、多分辨率和回归套件通过。 |

## 必须补测

1. 时间轴四边越界、旋转、冲突、Clear 空/部分/多命中、多格只执行一次。
2. 中毒叠加、扩散、每层10% HP、减层、死亡目标、同周期感染。
3. 高度1、6、0、7、8，建筑高度要求，毁灭和意图失效。
4. 10%阈值、同时胜负、奖励取消、重复确认、建筑奖励消费。
5. 商店不足/负资源/重复购买、三选一、删卡、两条合成配方。
6. 战斗中退出、转场 Esc、进程重启、损坏 cfg、旧版本字段、写入中断。
7. 键盘焦点、窗口失焦、快速连点、全屏、1280×720/1920×1080/2560×1080。
8. 每张卡、每种建筑、精英/事件/Boss、普通/真结局至少一条 OBSERVED。

## 通过标准

- 每例记录输入、前置、期望、实际、截图、日志、存档差异。
- 未验证写 UNVERIFIED；不可达写 BLOCKED 并附证据。
- 修复后重跑自然流程；静态检查和直接场景不能替代。
