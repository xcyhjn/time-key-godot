# 时间轴规则

## AS_IS

- 内部坐标 0 基：X=0..11 共 12 列，Y=0..2 共 3 层；玩家语义为 3×12。
- 行动含类型、来源、目标、形状、原点、颜色、效果数据和意图优先级。
- 放置条件：原点在界内；全部绝对坐标不越界；任何格不得已被占用。
- 同一多格行动的所有格都指向同一 `TimelineAction`。
- 结算前以 36 减占用格数计算空格，按 `empty_slot_ratio=1.0` 转时间币。
- 结算顺序为列从左到右、层从上到下；`processed_actions` 保证多格行动只执行一次。
- 每项行动交给 `EffectProcessor` 并等待动画/命令；有行动的列额外停 0.2 秒。
- 敌方意图优先级高者先放，同级可随机；最多 5 项。

## OBSERVED

普通战斗可见红色敌方占位；中毒牌选中、目标选择和多格拖拽预览已观察。中毒伤害没有形成独立数值截图，不能写成行为已验证。

## 边界

| 情况 | 当前实现 | QA |
| --- | --- | --- |
| 四边越界 | 返回 false | 四边分别拖拽，卡不消耗 |
| 重叠 | 已占格拒绝 | 玩家/敌方/多格三类 |
| 空形状 | 普通解析回退；Clear 走专用模式 | 非法字符、空数组、`0` |
| Clear 空命中 | 代码路径存在 | 固化消耗或返还 |
| 目标变化 | 敌意有重验证 | 玩家提交也二次判定 |
| 同 ID 多实例 | 按对象实例区分 | 两张同牌分别结算 |

## 差异

| 项目 | AS_IS | DESIGN_INTENT | PROPOSED |
| --- | --- | --- | --- |
| 尺寸 | 12列×3层 | 3×12 | 术语统一为“12列×3层（3×12）” |
| 顺序 | 列优先、层优先、多格一次 | 最靠前占位格决定 | 增加行动 ID 日志 |
| 敌意密度 | 上限 5 | 5–7 | 当前值写 5，目标值另列 |
