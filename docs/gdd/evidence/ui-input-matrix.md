# UI 与输入矩阵

| 区域 | 输入 | 当前反馈 | 状态 |
| --- | --- | --- | --- |
| 主菜单 | 点击六个按钮 | hover/pressed/黑幕转场 | 已观察主要命令 |
| 种子 | 文本+Enter | 以字符串 hash 生成地图 | 已观察 |
| 角色 | 相邻节点、确定、退出、Esc | 角色页、确认收缩扇区、取消回退 | 已观察/源码 |
| 局外 | 左键相邻节点 | 移动或切房间 | 已观察普通节点 |
| 卡牌 | 左键选中、目标、拖轴、右键取消 | 升起、tooltip、蓝/红预览、回手 | 部分观察 |
| 牌堆 | 左/右键 | 当前配置打开查看器，不直接抽牌 | 已观察 |
| 时间轴 | 拖拽、格点击 | 形状预览、越界/重叠拒绝 | 部分观察 |
| 结束回合 | 点击 | 锁输入、弃牌、结算、下一回合 | 已观察 |
| 视角切换 | 点击 | 平铺/高度入口 | 入口已见，细节未验证 |
| 暂停 | Esc | 音量、全屏、速度、保存、退出、返回 | 已观察 |
| 失焦、键盘焦点、快速连点 | 未逐项完成 | 需专项 QA | UNVERIFIED |

## PROPOSED

所有按钮提供中文焦点态；Esc 只关闭最高优先级模态；转场和结算期间全局锁输入；滑条支持键盘并显示值；窗口失焦不推进回合；拖拽取消必须无资源副作用。
