# 成长与经济

## 当前值

- 时间币：空时间轴格数×1.0，向下取整；不能通过正常接口变成负数。
- 商店：8 商品位、4 列；基础价格50，槽位步进5，价格增量25；刷新50，升级100。
- 商店时代权重：当前85%、前一5%、后一9%、后两时代1%。
- 获取卡牌：当前时代牌池随机三选一。
- 删卡：从当前牌组选择一张确认删除。
- 合成：`wind+tower -> tornado`；`lighting+earthquake -> poison`。
- 反思点、特殊时代牌和遗物是旧策划案意图，本轮没有当前自然流程证据。
