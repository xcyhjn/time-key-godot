# 局外地图规则

## AS_IS

- 六边形地图半径默认 12，章节边界为 [4,8,12]。
- 中心是 START；半径 1 的六格是六个角色；半径 4/8/12 是 Boss。
- 其余格按空洞率 0.7 和权重生成：普通60、精英15、事件15、山地10。
- 生成后为每个角色扇区确保至少一条到半径12的路径，必要时把阻断格改为普通节点。
- 普通格分配强化、删卡、合成、交易图标；每层尝试强化×3、删卡×2、合成×1、交易×2。
- 玩家只能点击相邻、正值、非移动中的格。角色确认后仅保留所选扇区。
- 房间 payload：`battle_normal seed`、`battle_elite seed`、`boss_stage seed`、`event_stage seed`。

## OBSERVED

随机新局与固定 seed 新局均生成可见地图，布局不同；“士兵”确认后地图收缩到所选扇区；普通节点能进入战斗。精英、事件、Boss 未自然到达。

## 差异

| 项目 | AS_IS | DESIGN_INTENT | PROPOSED |
| --- | --- | --- | --- |
| 时代推进 | 主要按回合阶段推进 | 每移动一格+1 | 明确节点推进的是阶段还是时代 |
| 房间类型 | 类型和 payload 存在 | 四类均可玩 | 建立每类最小固定 seed 夹具 |
| 回原点/弑神 | 无稳定运行证据 | 真结局核心路线 | MapState 增加返程/神使/原点状态 |
